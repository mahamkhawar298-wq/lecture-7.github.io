# Pro Age Calculator | Interactive JavaScript Lab

A professional age calculator with moving lights background, corner-restricted animated cat, and multiple JavaScript function demos.

## Features

- Age calculation from birth year
- Voting eligibility checker
- Personal intro generator
- Addition function demo
- Loop counter (1 to 10)
- Positive/Negative number classifier
- Run all features button
- Console-style output display
- Moving cat restricted to bottom-right corner
- Animated light aura background

## Tech Stack

HTML5 · CSS3 (Glassmorphism, Animations) · JavaScript

## Functions Available

| Function | Description |
|----------|-------------|
| `calculateAge(year)` | Returns age from birth year |
| `checkVoting(age)` | Returns eligibility status |
| `add(a, b)` | Returns sum of two numbers |
| `printOneToTen()` | Logs numbers 1-10 |
| `posNeg(n)` | Returns positive/negative/zero |

## Quick Start

Open `index.html` in any modern browser.

## Interactive Elements

- **Input fields:** Name, Birth Year, Favorite Movie
- **Buttons:** Age, Vote, Intro, Add, Loop, Pos/Neg, Run All, Clear
- **Moving Cat:** Follows cursor but stays in bottom-right corner
- **Console Output:** Timestamped logs with colored formatting
